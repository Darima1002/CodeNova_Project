# StudyBuddy
StudyBuddy is a student assignment and study management application created by Team CodeNova for our capstone project.

The main purpose of StudyBuddy is to help students keep their schoolwork organized in one place. 
Students will be able to add their courses and assignments, enter due dates, and keep track of what assignments they still need to complete.

## Features

- Create an account and log in
- Add courses
- Add, edit, and delete assignments
- Add due dates
- Mark assignments as Not Started, In Progress, or Completed
- View upcoming assignments and deadlines
